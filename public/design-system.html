Vitruvius Design System

Visual reference for colors, typography, components, and patterns used across the Vitruvius Modeler UI. There are two design modes in one app — the App Shell and the UML Canvas — each with its own visual grammar.

React 18 · TypeScript Inline styles (no Tailwind / CSS-in-JS library) Accent: #049484 jjodel-inspired UML canvas

06 — Shadows & Elevation
Elevation system
Shadows float surfaces. Never apply to inline text or static UI elements. UML nodes are flat by default — shadow only on selection.
Flat
No shadow. Full-bleed surfaces, sidebar, table headers.
{shadow.xs}
Table container, UML diagram preview card.
{shadow.sm}
Cards, React Flow controls, avatar button.
{shadow.md}
Dropdown menus, sidebar user popup.
{shadow.header}
App header — tinted with brand color.
{shadow.modal}
Full modals, large dialogs.
{shadow.uml-focus}
Selected UML node glow. Teal ring.

Auth card. Auth page only.
